# Iris Flower Classification Using Machine Learning

## Project Overview
This project is a Python-based machine learning application developed as part of an Object-Oriented Programming course. It uses the Iris dataset to classify flower species based on their physical characteristics.

The project demonstrates object-oriented programming principles, data exploration, visualization, and supervised machine learning.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Logistic Regression
- Object-Oriented Programming (OOP)

## Project Features
- Loading and exploring the Iris dataset
- Visualizing data using scatter plots and histograms
- Splitting the dataset into training and testing sets
- Training a Logistic Regression model
- Evaluating model accuracy
- Graphical User Interface (GUI)

## Project Structure
- `main.py` – Main program
- `data_loader.py` – Dataset loading and exploration
- `visualization.py` – Data visualization
- `model.py` – Model training and evaluation
- `gui.py` – Graphical User Interface

## How to Run
1. Download or clone the repository.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Run the program:
   `python main.py`
